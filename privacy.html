3. Local Storage

This game uses the browser's local storage only for functions requested by the player. The stored information remains in the browser on the user's device and is not transmitted to the operator of this website.

Highscore: When a qualifying score is saved, the browser stores the selected player name or pseudonym, score, creation time and a locally generated identifier. A real name is not required. The highscore table is limited to 100 entries. A temporary marker for the newest entry is removed when the related highscore flow is closed.

Audio settings: If the player changes audio settings, the selected music volume, effects volume and mute state can be stored locally so that these settings remain available on later visits.

Local-storage entries remain on the device until they are replaced by the game, removed by the relevant game logic or deleted through the browser settings. The storage is used solely for the requested game functions and not for tracking, advertising or profiling. To the extent that Section 25 TDDDG applies to storing or reading these entries, the processing is based on Section 25(2)(2) TDDDG for functions explicitly requested by the user.

If a chosen player name constitutes personal data, the processing serves the local highscore function. The legal basis is Art. 6(1)(f) GDPR; the legitimate interest is providing this user-requested game feature while keeping the data exclusively on the user's device.
